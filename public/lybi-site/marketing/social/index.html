Price reference

Official per-second list prices (720p, with audio) from the model makers, next to what Leonardo charged us. Leonardo adds a markup: buying the same model directly (Google Gemini API, fal.ai, the maker's own API) is usually cheaper, at the cost of another account.

How we tested

  • Start frames: made once with Leonardo GPT Image 2 (2048×1152) from the brief's character and set descriptions, then given to every model as the first frame (Gemini Omni Flash takes no first frame, so it got the same picture as a strong image reference).
  • Prompt: the brief's spoken lines verbatim, who says each one, the action (lowered phone / box back into the bag), "understated", "restrained camera", "no music".
  • Words: every clip's audio was transcribed (Whisper) and compared to the script. Lips, who-speaks and acting were judged by eye.
  • Each model got one try per scene. A model can be lucky or unlucky on one take, so treat close calls as close.
  • Sources for list prices: invideo price survey (Aug 2026), Leonardo API docs, Leonardo credit costs.
